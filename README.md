# PizdaBot - Telegram Bot с Пользовательскими Триггерами и Системой Обратной Связи

## Описание

Telegram бот, который отвечает на различные фразы забавными ответами. Поддерживает как глобальные триггеры из кода, так и пользовательские локальные триггеры для каждого чата. 
**Новинки**: полное управление ботом в чате, настройка вероятности ответов и **система обратной связи**!

## Возможности

### 🔥 Пользовательские триггеры

• Участники чата могут добавлять свои собственные триггеры с ответами
• Пользовательские триггеры имеют приоритет над глобальными
• Лимиты на количество триггеров (3 в день на пользователя, до 50 на чат)
• Валидация длины триггера (2-100 символов) и ответа (1-500 символов)
• Возможность удаления своих триггеров или всех (для админов)

### ⚙️ Управление ботом в чате

• **Полное отключение/включение бота** командами `/off` и `/on`• **Настройка вероятности ответа** от 0 до 100% командой `/chance`
• **Просмотр настроек чата** командой `/settings`
• **Индивидуальные настройки** для каждого чата сохраняются автоматически

### 📝 Система обратной связи (НОВАЯ ФУНКЦИЯ!)

• **Отправка обращений пользователями** через команду `/feedback`
• **Поддержка текстовых сообщений до 2000 символов**• **Уведомления администраторов** о новых обращениях в реальном времени
• **Управление обращениями**: просмотр, отметка как прочитанные, удаление
• **Статистика по обращениям** с детальной аналитикой
• **Безопасность**: только автор может подтвердить свое обращение
• **Автоматическое сохранение** всех обращений в базе данных

### 📊 Статистика

• Общая статистика использования бота
• Топ самых популярных триггеров
• Статистика за день
• Персональная статистика пользователя
• **Статистика по обращениям**: общие показатели, непрочитанные, по пользователям

### 👑 Админские функции

• Детальная статистика с информацией по пользователям
• Экспорт статистики в JSON• Очистка статистики
• Удаление любых пользовательских триггеров
• Сброс настроек чата к значениям по умолчанию
• **Полное управление системой обратной связи**

## Команды

### ⚙️ Управление ботом:

• `/on` - включить бота в чате
• `/off` - выключить бота в чате
• `/chance <0-100>` - установить вероятность ответа в процентах
• `/settings` - показать текущие настройки чата

**Примеры использования управления:**

    /chance 50 # Бот отвечает в 50% случаев
    /chance 0 # Бот не отвечает на триггеры
    /chance 100 # Бот отвечает всегда (по умолчанию)
    /off # Полностью отключить бота в чате
    /on # Включить бота обратно

### 📝 Система обратной связи:

• `/feedback` - отправить обращение администраторам

### Для всех пользователей:

• `/start` - приветствие бота
• `/help` - справка по командам
• `/stats` - общая статистика
• `/top` - топ-10 триггеров
• `/today` - статистика за сегодня

### Пользовательские триггеры:

• `/add "фраза" "ответ"` - добавить триггер
• `/remove "фраза"` - удалить свой триггер
• `/triggers` - список триггеров чата
• `/my_triggers` - ваша статистика по триггерам

### Только для админов:

• `/admin_stats` - детальная статистика
• `/export_stats` - экспорт статистики в JSON файл
• `/clear_stats` - очистить всю статистику
• `/remove_all_triggers` - удалить все триггеры чата
• `/reset_settings` - сбросить настройки чата

**Команды управления обратной связью (только для админов):**
• `/admin_register` - регистрация для получения уведомлений о новых обращениях
• `/admin_feedback` - просмотр всех обращений
• `/feedback_unread` - показать только непрочитанные обращения
• `/feedback_detail <ID>` - детальный просмотр обращения по ID
• `/feedback_stats` - статистика по обращениям
• `/feedback_mark_all_read` - отметить все обращения как прочитанные
• `/feedback_delete <ID>` - удалить обращение
• `/feedback_user <user_id>` - все обращения конкретного пользователя
• `/admin_help` - справка по административным командам

## Система обратной связи - подробное описание

### Для пользователей:

1. **Отправка обращения**: используйте команду `/feedback`
2. **Написание сообщения**: введите любой текст (от 5 до 2000 символов)
3. **Подтверждение**: проверьте предварительный просмотр и подтвердите отправку
4. **Получение ID**: каждое обращение получает уникальный номер для отслеживания

### Для администраторов:

1. **Регистрация**: выполните `/admin_register` для получения уведомлений
2. **Уведомления**: получайте мгновенные уведомления о новых обращениях
3. **Просмотр**: используйте `/admin_feedback` для просмотра всех обращений
4. **Управление**: отмечайте как прочитанные, удаляйте, фильтруйте по пользователям

### Возможности системы:

* **Анонимность**: администраторы видят username, но пользователи остаются анонимными
* **История**: полная история всех обращений с временными метками
* **Статистика**: детальная аналитика по обращениям
* **Безопасность**: защита от подделки обращений
* **Масштабируемость**: поддержка неограниченного количества обращений

## Файлы данных

Бот использует базу данных MySQL/SQLite для хранения:

* **Таблица `feedback`** - все обращения пользователей
* **Таблица `admin_chat_registry`** - зарегистрированные администраторы
* Остальные существующие таблицы для триггеров, статистики и настроек

## Особенности новой версии

### 🎯 Умное управление

• **Индивидуальные настройки**: каждый чат имеет свои настройки• **Вероятностные ответы**: настройте частоту срабатывания от 0 до 100%• **Полное отключение**: команда `/off` полностью отключает бота в конкретном чате• **Сохранение состояния**: настройки сохраняются между перезапусками

### 🔧 Логика работы

1. **Проверка настроек**: бот сначала проверяет, включен ли он в чате
2. **Вероятность**: если включен, проверяет процент вероятности ответа
3. **Приоритет триггеров**: пользовательские → глобальные
4. **Статистика**: все ответы учитываются в статистике

### 📝 Новая система обратной связи

1. **FSM состояния**: использует aiogram FSM для многоэтапного процесса
2. **Валидация**: проверка длины и содержимого сообщений
3. **Предварительный просмотр**: пользователь видит, как будет выглядеть обращение
4. **Уведомления**: мгновенные уведомления всем зарегистрированным админам
5. **База данных**: все обращения сохраняются с полной информацией
