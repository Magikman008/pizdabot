# PizdaBot - Telegram Bot с Пользовательскими Триггерами

## Описание
Telegram бот, который отвечает на различные фразы забавными ответами. Поддерживает как глобальные триггеры из кода, так и пользовательские локальные триггеры для каждого чата.

## Возможности

### 🔥 Пользовательские триггеры
- Участники чата могут добавлять свои собственные триггеры с ответами
- Пользовательские триггеры имеют приоритет над глобальными
- Лимиты на количество триггеров (3 в день на пользователя, до 20 на чат)
- Валидация длины триггера (3-50 символов) и ответа (1-200 символов)
- Возможность удаления своих триггеров или всех (для админов)

### 📊 Статистика
- Общая статистика использования бота
- Топ самых популярных триггеров
- Статистика за день
- Персональная статистика пользователя

### 👑 Админские функции
- Детальная статистика с информацией по пользователям
- Экспорт статистики в JSON
- Очистка статистики
- Удаление любых пользовательских триггеров

## Команды

### Для всех пользователей:
- `/start` - приветствие бота
- `/help` - справка по командам
- `/stats` - общая статистика
- `/top` - топ-10 триггеров 
- `/today` - статистика за сегодня

### Пользовательские триггеры:
- `/add "фраза" "ответ"` - добавить триггер
- `/remove "фраза"` - удалить свой триггер
- `/triggers` - список триггеров чата
- `/my_triggers` - ваша статистика по триггерам

### Только для админов:
- `/admin_stats` - детальная статистика
- `/export_stats` - экспорт статистики в JSON файл
- `/clear_stats` - очистить всю статистику

## Установка и настройка

1. **Клонируйте репозиторий:**
   ```bash
   git clone <repository-url>
   cd pizdabot
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Настройте бота:**
   - Создайте бота через [@BotFather](https://t.me/BotFather) в Telegram
   - Скопируйте `settings.py.example` в `settings.py`
   - Замените `YOUR_BOT_TOKEN_HERE` на токен вашего бота

4. **Настройте администраторов** (опционально):
   - В файле `app/app.py` в переменной `ADMIN_USERNAMES` укажите username администраторов

5. **Запустите бота:**
   ```bash
   python -m app.app
   ```

## Файлы данных

Бот автоматически создает следующие файлы для хранения данных:
- `bot_stats.json` - статистика использования бота  
- `user_triggers.json` - пользовательские триггеры

## Особенности

- **Приоритет триггеров**: пользовательские триггеры имеют приоритет над глобальными
- **Безопасность**: админские команды скрыты от обычных пользователей
- **Лимиты**: ограничения на количество триггеров предотвращают спам
- **Валидация**: проверка входных данных на корректность
- **Статистика**: подробная аналитика использования
